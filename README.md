# Qavryon 0.1.0

Prototipo Android jugable. Pulsa JUGAR y toca la bolita azul el mayor número de veces durante 30 segundos.

## Abrir
1. Instala Android Studio.
2. Abre esta carpeta como proyecto.
3. Espera la sincronización de Gradle.
4. Ejecuta en un teléfono Android o emulador.

Próxima fase: pantalla de perfil, economía/recompensas, conexión segura con backend y la interfaz de la bolita azul.
